# prova-sito

Sito di prova di Go Ital IA: serve a provare la pubblicazione dal Modulo Sviluppo (pezzo 10).
Va online su https://prova-sito.unvrslabs.dev (server di prova, mai produzione).

- `npm run build`: copia `src/` in `dist/`
- `npm test`: controlla che `src/index.html` esista

Il ramo `main` e' protetto: si cambia solo con una richiesta (pull request).
